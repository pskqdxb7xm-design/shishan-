## 五、人工真机验收清单 (E2E)

### 核心主流程

- [ ] **首次启动** → 自动静默登录 → 首页加载成功，有帖子
- [ ] **城市选择** → 点击城市 → 弹城市选择页 → 选一个城市 → 返回刷新
- [ ] **发布帖子** → 点 + → 选图 → 填标题/时间/地点/人数 → 勾协议 → 发布成功
- [ ] **帖子详情** → 点帖子 → 看到图片轮播、作者信息、评论
- [ ] **发评论** → 输入文字 → 发送 → 评论立刻出现
- [ ] **回复评论** → 点回复 → 输入文字 → 发送 → 回复出现在对应评论下
- [ ] **收藏** → 点☆ → 变★ → 已收藏状态
- [ ] **申请加入** → 点申请 → 勾授权 → 确认 → 等待审核状态
- [ ] **查看消息** → 切消息 Tab → 看到通知 → 点通知跳详情
- [ ] **我的页面** → 切我的 Tab → 看到昵称/头像/三Tab
- [ ] **编辑资料** → 点编辑 → 改昵称/微信号/MBTI → 保存
- [ ] **生成海报** → 进详情 → 更多 → 海报 → 保存到相册
- [ ] **拉黑用户** → 详情 → 更多 → 拉黑 → 主页不再看到该用户帖子

### 异常场景

- [ ] **断网** → 操作任何按钮 → Toast 提示，不白屏
- [ ] **拒绝定位** → 首页默认显示"全国"，同城 Tab 无数据
- [ ] **输入超长文本** → 标题 50 字/评论 200 字 → 自动截断
- [ ] **连击防抖** → 连续快点"发布"/"申请" → 不会重复提交
- [ ] **空列表** → 消息为空/帖子为空 → 显示空状态提示
- [ ] **下拉刷新** → 首页下拉 → 重新加载

### UI 兼容

- [ ] **iPhone 底部安全区** → 底部输入栏不被小黑条遮挡
- [ ] **刘海屏** → 顶部状态栏高度适配正确
- [ ] **Android 键盘** → 弹起键盘不遮挡输入框
- [ ] **搜索框** → 输入流畅不卡顿
